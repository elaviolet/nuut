# NUUT — The Celestial Goddess

### A Celestial Polyphonic Synthesizer

NUUT is an experimental polyphonic synthesizer inspired by celestial
harmony, astronomical relationships and the idea of sound as a constellation.

The instrument explores harmonic relationships, evolving polyphonic structures
and crystal-inspired sound transformations.

NUUT is being developed as an instrument for the Synthux Academy Touch 2,
built around the Electro-Smith Daisy Seed platform.
